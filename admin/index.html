Website admin

Sign in with a GitHub access token for this website's repository. Only people who hold a token can change the site.

How do I get a token?
  1. On GitHub open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Choose Only select repositories and pick laftah-website.
  3. Under Repository permissions set Contents to Read and write. Leave everything else off.
  4. Pick an expiry, generate it, and paste it here. It is shown only once.
